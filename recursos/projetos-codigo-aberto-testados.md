# 41 projetos de código aberto com o link conferido

Consulta: **24/11/2026**. Uma lista com 99 projetos "com código-fonte" circulou no Instagram em novembro de 2026. Antes de salvar, cada endereço foi aberto pela API pública do GitHub. O resultado:

| O que aconteceu com o link | Quantos |
| --- | --- |
| Não abre (erro 404: repositório ou pasta inexistente) | 56 |
| Abre, mas leva a outra coisa (o título fala de um jogo de perguntas e o link é um painel de covid, por exemplo) | 3 |
| Abre e corresponde ao título | 40 |

Um dos 56 só tinha uma letra trocada no endereço e foi corrigido. Sobraram **41 links que funcionam**, organizados abaixo pelo uso.

## O que "gratuito" quer dizer aqui

Código aberto significa que você pode baixar e instalar no seu próprio servidor sem pagar licença. O custo passa a ser o servidor e o tempo de quem cuida dele. Vários desses projetos também vendem uma versão hospedada por eles: a nuvem é paga, o código continua gratuito.

Confira sempre a licença antes de usar num produto. Onde a tabela diz "ver repositório", o projeto usa uma licença própria ou mais de uma. Onde diz "não declarada", o autor publicou o código sem liberar o reuso: serve para estudar, não para copiar num produto.

## O que ficou de fora

- **56 links que não abrem.** Parte dos endereços tem cara de inventada: usuários como `johndoe` e organizações com o mesmo nome do projeto.
- **3 links que abrem outra coisa.** Um "jogo de perguntas" que leva a um painel de covid, uma "plataforma de games" que leva a uma lista de canais de TV e um "aplicativo de orçamento" que leva a uma lista de leituras sobre React.

Sete projetos mudaram de endereço desde que a lista foi montada (o GitHub redireciona). As tabelas acima já usam o endereço atual.

## Como conferir você mesmo

Estrelas, licença e data do último envio mudam. Para repetir a conferência de um repositório, com a [CLI do GitHub](https://cli.github.com/) instalada:

```bash
gh api repos/metabase/metabase --jq '[.full_name, .stargazers_count, .license.spdx_id, .pushed_at, .archived]'
```

Resposta `Not Found` significa que o endereço não existe. Um link abrir não diz nada sobre a qualidade ou a segurança do código: antes de instalar qualquer coisa em servidor da empresa, leia a licença, veja a data do último envio e os problemas abertos.
