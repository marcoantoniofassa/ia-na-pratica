# Comece aqui, sem precisar programar

Esta coleção oferece textos para pedir ajuda à IA e conferir o que ela entrega. Para começar, basta conseguir copiar e colar uma mensagem.

## Primeiro uso

1. Escolha [organizar um pedido](../prompts/organizar-pedido.md).
2. Copie somente o bloco marcado como prompt.
3. Troque os campos entre colchetes pelo seu caso. Se não souber algo, escreva “não sei”.
4. Cole na conversa com a IA que você já utiliza.
5. Confira se a resposta respeita o objetivo e os limites que você informou.

**Exemplo fictício:** “Uma pequena loja recebe pedidos por mensagens. Precisa registrar cliente, produto e status, sem contratar outro serviço neste mês.” Uma proposta útil deve respeitar esse limite e mostrar como conferir um pedido do início ao fim.

## O que a IA consegue ver?

Um chat comum só consegue analisar o conteúdo fornecido e as ferramentas disponíveis nele. Não presuma acesso ao computador, ao site ou aos documentos de outra conversa.

Para explicar um projeto, use uma ferramenta autorizada a ler a pasta indicada ou forneça um trecho sem dados confidenciais. Sem acesso, a resposta deve dizer o que falta. Uma instrução de teste não é prova de que o teste aconteceu.

## Quando usar uma skill

Se você repete a mesma tarefa em um agente que aceita skills, instalar as instruções pode reduzir o trabalho de copiá-las. Leia [o guia de instalação](instalar-skills.md) quando isso fizer sentido. Não é requisito para o primeiro uso.

## Tradução dos termos

| Termo | Em linguagem comum |
| --- | --- |
| Prompt | O pedido enviado à IA. |
| Skill | Instruções reutilizáveis para uma tarefa. |
| Agente | IA com ferramentas para agir, como ler arquivos ou executar comandos, conforme as permissões. |
| Repositório | Pasta de um projeto com histórico de alterações; pode ser hospedada no GitHub. |
| Terminal | Aplicativo em que comandos são digitados e executados no computador. |
| Produção | O sistema em uso por pessoas reais. |
| Sandbox | Ambiente com restrições técnicas que limitam o que um programa pode acessar ou alterar. |
| Evidência | Arquivo, fonte, observação ou resultado que permite conferir uma afirmação. |

## Antes de aceitar uma entrega

Peça para a IA mostrar o que fez, onde está o resultado e como conferiu. Se uma etapa não foi executada, ela deve aparecer como pendente.

Não envie senhas, códigos de acesso nem documentos privados para experimentar. Ao usar dados de uma empresa, respeite as ferramentas e os compartilhamentos autorizados por ela.

Para discutir segurança com a equipe, use o [guia técnico](auditoria-seguranca.md). Ele não exige que uma pessoa sem experiência rode testes de invasão.
