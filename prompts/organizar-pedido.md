# Organizar um pedido

**Para quem:** tem uma ideia e quer pedir a execução com clareza.
**Precisa de:** problema, público e limites conhecidos. **Resultado:** um pedido pronto para revisar e encaminhar.

## Copie este prompt

```text
Transforme esta ideia em um pedido claro: [ideia].
Quem precisa disso: [público]. O problema de hoje: [problema].
Resultado desejado: [resultado]. Limites: [prazo, custo, acessos e restrições].

Organize objetivo, menor entrega útil, o que fica fora e como conferir o resultado.
Use um exemplo de uso para explicar o que seria uma entrega satisfatória.
Separe informações fornecidas de suposições. Se algo essencial estiver faltando,
faça uma pergunta curta; siga com hipóteses explícitas no que for independente.
Não invente orçamento, prazo, consenso ou autorização.
Esta etapa prepara o pedido. Não crie contas, contrate serviços, publique
nem envie mensagens. Entregue o texto para revisão.
```

**Confira:** outra pessoa consegue entender quando a tarefa estará concluída?
