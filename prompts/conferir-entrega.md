# Conferir uma entrega

**Para quem:** recebeu um documento, relatório ou projeto e quer comparar com o combinado.
**Precisa de:** pedido original e material entregue. **Resultado:** pendências acompanhadas de evidências.

## Copie este prompt

```text
Confira esta entrega contra o pedido original.
Pedido e critérios: [texto ou arquivo].
Entrega e evidências disponíveis: [material autorizado].

Faça uma revisão sem alterar a entrega. Para cada requisito relevante,
indique atendido, não atendido ou não verificável, citando a evidência.
Uma afirmação de que algo foi testado não equivale ao resultado do teste.
Não conclua que uma função está ausente só porque faltou acesso para observá-la.
Se houver contradição entre fontes, mostre-a e explique o que falta conferir.
Diferencie o que impede aceitar a entrega de sugestões opcionais.
Termine com uma recomendação e a menor lista de pendências necessária.
Não publique, envie mensagens ou execute código para completar esta revisão.
```

**Confira:** cada pendência aponta o requisito e o material que sustenta a conclusão?
