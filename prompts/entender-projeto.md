# Entender um projeto

**Para quem:** precisa entender o que existe sem receber uma aula de programação.
**Precisa de:** uma descrição, documentos ou uma pasta acessível ao agente. **Resultado:** mapa simples com evidências e lacunas.

## Copie este prompt

```text
Explique este projeto para uma pessoa que não programa.
Material autorizado: [pasta, documentos ou descrição].
Decisão que a explicação deve ajudar: [objetivo].

Leia somente esse material. Não altere nem execute arquivos.
Explique para que serve, quem usa e quais partes sustentam o funcionamento.
Traduza os termos técnicos na primeira vez que aparecerem.
Aponte a fonte de cada conclusão relevante e separe observado de inferido.
Não presuma que um arquivo de configuração corresponde ao sistema no ar.
Se faltar acesso, diga o que não foi visto e qual informação resolveria a dúvida.
Termine com o próximo passo útil para a decisão informada.
```

**Confira:** a resposta identifica o material que leu e deixa claro o que não consegue saber?
