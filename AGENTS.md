# Instruções deste repositório

Este repositório contém documentação e um prompt reutilizável em português. Não é um scanner e não executa auditorias automaticamente.

- Preserve a distinção entre alerta de ferramenta, hipótese e falha demonstrada.
- Confira o README e o SKILL.md oficiais da Cloudflare antes de atualizar instruções sobre a skill.
- Não adicione credenciais, exemplos internos, logs, resultados de clientes ou dados de produção.
- Mantenha a auditoria sem alterações de produto e preserve os requisitos de isolamento, verificação independente e autorização de produção.
- Verifique links relativos, fidelidade à fonte oficial e ausência de dados sensíveis antes de publicar mudanças.
- Não há aplicação, build, dependências ou suíte de testes neste repositório. Não invente gates.
